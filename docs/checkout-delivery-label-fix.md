# Подписи доставки в checkout — 03.11.2026

При мобильной проверке действующего сайта бесплатная доставка первой строкой была переименована в «Товары — 0 RUB». Причина: markTotals определял первую строку как стоимость товаров независимо от её содержимого.

Исправление определяет доставку по штатному элементу адреса, скидку по её подписи, подытог товаров по метке «Сумма»/«Товары» или переводу subtotal в текущей Тильде, итог по штатному элементу общей суммы. Неизвестная строка не переименовывается в товары. Если старая версия уже испортила подпись доставки, она восстанавливается из имени текущей доставки; денежные значения не меняются.

Проверены синтаксис JS, 27 существующих тестов и 25 изолированных браузерных проверок с текущими функциями Тильды. Дополнительно проверены: бесплатная/платная доставка без подытога товаров, восстановление уже испорченной подписи, первая строка скидки и суммы со скидкой, настоящий подытог, доставка после товаров и повторная обработка без дубликатов.

Браузер: ПК и viewport 390×844, фактическая ширина 390 px, ширина документа 375 px. Временный viewport сброшен. Сценарий tests/checkout-totals.html запускается из локального HTTP-сервера, без реальных заказов и персональных данных. Скриншот cart-delivery-label-fixed-mobile.png сохранён в рабочей папке проекта.

Подготовлено в отдельной ветке; main и действующий сайт не изменялись. После публикации потребуется повторная проверка реального checkout. Архив клуба и условия 11.11 не меняются.
