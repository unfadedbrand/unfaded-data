# Корзина 11.11 — подготовлено 02.11.2026, не опубликовано

Макет: исходная интерактивная корзина Claude от 26.10, утверждённая Лерой повторно 02.11 с реальными фотографиями, Onest и цветами действующего сайта.

## Где находится изменение

- `cart-1111.js`: представление акции и подборка до четырёх товаров, работа с текущими остатками Тильды.
- `brand-popup-fix.js`: небольшой загрузчик и отключение прежней подборки только на время новой акции.
- `brand-style.css`: стили корзины с существующими брендовыми переменными.
- `tests/cart-1111.test.cjs`: проверки расчётов, исключений, размеров и структуры добавляемой позиции.

В HEAD Тильды ничего не добавлять: лимит уже использован. На сайте уже подключены `brand-popup-fix.min.js` и `brand-style.min.css` с GitHub Pages. После отдельного разрешения на публикацию основная ветка соберёт сжатые файлы штатным workflow. Новый модуль загрузится из этого же репозитория. Минифицированные файлы вручную не менять.

## Текущее состояние

Загрузчик оставлен с `enabled: false`. Работа сохранена отдельно от основной ветки; существующий сайт не меняется. Даже случайное слияние не включает корзину акции без изменения флага.

Перед выпуском проверить код, заполнить `lamodaFullPriceSkus` актуальным списком моделей без скидки на Lamoda и установить `enabled: true` по отдельному разрешению Леры. Пустой список не выдаёт предположений о ценах Lamoda: работают приоритеты образ → новинки → остальные.

Время оформления акции задано с явным смещением Москвы: 08.11.2026 19:00 включительно — 13.11.2026 00:00 исключительно. Начало самой скидки Тильды 08.11 18:45 менять не нужно. Предпросмотр вне этого окна разрешён только на localhost; query-параметр на действующем сайте не обходит расписание.

## Поведение

- Шкала 1/2/3+ вещи → 11/22/33%, подсказка экономии, цена товаров до скидки, скидка, итог товаров. Штатный окончательный итог с доставкой и форма Тильды остаются на месте.
- НГ-капсула исключается по разделу 690719490763 и точным артикулам FW26. Прошлогодняя NY26 и Heartbreaker участвуют. Товары архива клуба не попадают в рекомендации.
- Реальная скидка и суммы берутся из `tcart` после применения штатной скидки Тильды. Код ничего не записывает в суммы, промокоды, цену товара или оплату. При ожидании расчёта либо победившем промокоде не показывает вымышленную скидку 11.11.
- Подборка: вещи утверждённого образа → новинки → переданный список моделей по полной цене Lamoda → остальные. Только подходящая категория и доступный выбранный размер. Уже находящаяся в корзине модель не предлагается снова. Если размера в корзине нет, размер S не угадывается.
- Индекс поиска используется лишь для категории. Фото, цены, варианты и остатки берутся из API каталога Тильды с пагинацией. Одновременно не более трёх запросов; кеш не дольше двух минут, перед добавлением обязательная повторная проверка наличия. При недоступности раздела его товары не предлагаются.
- Добавление использует штатную форму позиции Тильды: edition uid, parent uid, recid, размеры, цвет, разделы, упаковка. Перерисовываются товары и суммы, но не поля формы. Ошибки наличия показываются в корзине.
- После окончания окна компоненты акции удаляются, прежние рекомендации могут снова работать.

Локальный браузерный прогон использует копию публичного ответа Тильды с 36 товарами: добавление рекомендации, смена ступени, три вещи, НГ-капсула, сохранение введённого имени, исчезнувший размер и выключение оформления. Это тестовая страница с адаптером корзины, а не отправка реального заказа.

Не выполнялись публикация, слияние, изменение HEAD/настроек Тильды, реальные заказы, оплата, отправка в CRM или фискализация. До запуска 08.11 обязательны сквозные тесты 1/2/3 вещи: сумма Тильды = RetailCRM = чек АТОЛ; НГ-исключения, CREDITS, доставка и обновление остатков. Внешние API/разметку Тильды ещё нужно проверить при интеграции на тестовой странице.
