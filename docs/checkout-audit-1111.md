## Блокировка следующего этапа

Подключённый инструмент RetailCRM сначала не ответил, затем вернул ошибку разбора адреса запроса. Причина в исходниках коннектора: RETAILCRM_URL принимает hostname без HTTPS как готовый URL.

Подготовлен отдельный черновик https://github.com/unfadedbrand/unfaded-retailcrm-connector/pull/1: нормализация hostname в HTTPS, проверка базового URL и безопасное сообщение при сетевой ошибке. Сборка TypeScript и три теста проходят с вымышленными учётными данными и подменённым fetch. Развёртывание не выполнялось. До обновления нужно подтвердить репозиторий активного сервиса Render и получить разрешение Леры на изменение отдельного коннектора.

После восстановления подключения остаются сквозные проверки 1/2/3 вещи, промокод/CREDITS, доставка, совпадение сумм Тильда → RetailCRM → АТОЛ. Они не считаются пройденными по результату текущего аудита. Заказ/оплата/фискализация требуют отдельного согласованного тестового сценария.
