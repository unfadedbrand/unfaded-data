# Разрешённое тестовое подключение 11.11, 02.11.2026

Лера разрешила выложить файлы для проверки по отдельной тестовой ссылке, оставив обычную главную без изменений. Этот PR направлен в main отдельно от черновиков #83/#84. Он не включает обычную акцию и не меняет Tilda HEAD, скидки, оплату, оформление, доставку, CRM или фискализацию.

- Баннер: `https://unfadedstore.com/?uf-review=1111-2026`
- Образы: `https://unfadedstore.com/?uf-page=looks-1111&uf-review=1111-2026`
- Обычная главная: `https://unfadedstore.com/` — загрузчик немедленно выходит до загрузки новых ресурсов.

Тестовый режим явно включён только в loader этой ветки и ограничен точным hostname, корневым pathname и query. Ссылка не является секретной или авторизацией; это просмотр без навигационных ссылок обычного сайта, с noindex. Подпись «ТЕСТ» объясняет, что штатная скидка включается только по расписанию акции. Работают реальные остатки и штатная корзина; заказ автоматически не отправляется. Промокоды, CREDITS и итог считает существующая Тильда.

`cart-1111.js` здесь используется только как общий код идентификации и подготовки позиции; его акционное оформление отключено (`UF1111_SETTINGS.enabled: false`). Стили нового оформления корзины и его загрузчик из #83 не выпускаются. Общий запуск кампании выключен (`UF1111_CAMPAIGN_SETTINGS.enabled: false`).

Файлы опубликованы через уже существующий загрузчик `brand-popup-fix.min.js` и штатный workflow минификации. Нового кода в HEAD Тильды нет. Перед слиянием проверены синтаксис JS и 27 проверок Node, включая блокировку review на обычной главной/другом домене/другом пути.
