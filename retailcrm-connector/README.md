# unfaded-retailcrm-connector

Постоянный коннектор Claude ↔ RetailCRM для UNFADED. Даёт Claude широкое чтение (заказы, клиенты, товары, остатки, справочники, аналитика) и точечную запись, которую вы включаете и выключаете переменными окружения — без переписывания кода.

## Важно прочитать перед установкой

Этот код написан и подробно вычитан, но **не запускался вживую** — в среде, где он собирался, нет доступа к npm-реестру и к вашему аккаунту RetailCRM, поэтому финальная проверка возможна только на реальном деплое. Если при первом запуске появится ошибка — пришлите её текст Claude в чат, это почти наверняка правится за одну правку.

Отдельно: несколько методов API (`ALLOW_LOYALTY`, `ALLOW_SEGMENTS`, `ALLOW_DICTIONARY_DRAFTS`) помечены в коде как **best-effort** — официальная документация RetailCRM не подтверждает однозначно, что эти методы существуют именно по тем путям, что зашиты в код. Если RetailCRM ответит ошибкой — сервер вернёт понятный текст вместо падения, и путь легко поправить. Триггеры и рассылки (`ALLOW_TRIGGERS`, `ALLOW_MAILINGS`) НЕ управляются через API RetailCRM вообще (подтверждено — в официальном PHP-клиенте RetailCRM нет таких сущностей) — соответствующие инструменты не пытаются вызвать API, а готовят готовый текст для ручного ввода в интерфейс.

## Что нужно подготовить в RetailCRM (5 минут)

1. **Настройки → Пользователи → Группы пользователей** — создайте группу, например «AI-коннектор». Права: просмотр заказов/клиентов/товаров/аналитики; **без** прав на возврат оплаты, массовые операции, администрирование, справочники.
2. **Настройки → Пользователи** — добавьте технического пользователя, включите его в эту группу.
3. Выпустите **API-ключ** для этого пользователя (обычно Настройки → Интеграция → Ключи API — если раздел называется иначе в вашей версии, поищите «API» через поиск по настройкам). Скопируйте ключ — он понадобится на шаге деплоя.

## Деплой (вариант Render.com, бесплатный тариф, ~10 минут, без программирования)

1. Зарегистрируйтесь на [render.com](https://render.com).
2. Загрузите папку `retailcrm-connector` в свой репозиторий на GitHub (можно через веб-интерфейс GitHub — «Add file → Upload files», без командной строки) **или** попросите Claude в новой сессии с доступом к вашему GitHub сделать это за вас.
3. В Render: New → Web Service → подключить этот репозиторий.
4. Build Command: `npm install && npm run build`
5. Start Command: `npm start`
6. В разделе **Environment** добавьте все переменные из `.env.example` с реальными значениями:
   - `RETAILCRM_URL` — адрес вашего аккаунта
   - `RETAILCRM_API_KEY` — ключ с шага выше
   - `CONNECTOR_TOKEN` — придумайте длинную случайную строку (например, сгенерируйте на [1password.com/password-generator](https://1password.com/password-generator) или любым похожим способом, 32+ символа)
   - Флаги `ALLOW_*` — оставьте `false`, включите только когда понадобится конкретная задача
7. Нажмите Deploy. Через пару минут сервис будет жить по адресу вида `https://unfaded-retailcrm-connector.onrender.com`.
8. Проверьте, что сервис жив: откройте `https://ваш-адрес.onrender.com/health` в браузере — должно показать `{"status":"ok"}`.

**Бесплатный тариф Render засыпает после 15 минут простоя** и просыпается ~30-60 секунд на первый запрос после паузы — для нерегулярного использования (когда вы обращаетесь к CRM время от времени в чате с Claude) это нормально и не мешает; если понадобится мгновенный отклик каждый раз — на Render есть недорогой платный тариф без засыпания.

## Подключение в claude.ai / Cowork

1. Settings → Connectors → Add custom connector.
2. URL: `https://ваш-адрес.onrender.com/mcp/ВАШ_CONNECTOR_TOKEN` (тот самый секрет из шага 6 — это и есть «замок» коннектора, без него сервер не ответит).
3. Сохраните — коннектор должен появиться подключённым, а его инструменты (`rc_list_orders`, `rc_get_order` и т.д.) станут видны Claude в любой новой сессии.

Если на этом шаге интерфейс попросит именно OAuth (а не просто URL) — это будет означать, что claude.ai в вашей версии требует более сложную схему авторизации, чем секрет-в-URL; напишите об этом Claude в чате, и мы адаптируем сервер под точный формат, который просит интерфейс.

## Как включать/выключать флаги записи

Render → ваш сервис → Environment → меняете значение нужного `ALLOW_*` на `true` → Save (сервис перезапустится сам за ~30 секунд) → просите Claude выполнить задачу → по готовности возвращаете `false`. Никакого нового деплоя не нужно.

## Ротация ключа

Если когда-нибудь захотите отозвать доступ — удалите/перевыпустите `RETAILCRM_API_KEY` в RetailCRM (доступ коннектора мгновенно пропадёт) или просто смените `CONNECTOR_TOKEN` в Render (старый URL перестанет работать).

## Структура проекта

- `src/config.ts` — переменные окружения и флаги
- `src/retailcrmClient.ts` — обёртка над REST API v5 RetailCRM
- `src/tools.ts` — все инструменты, которые видит Claude (чтение без флагов, запись — за флагами)
- `src/draftTools.ts` — генераторы текста для триггеров/рассылок/сегментов (без обращения к API)
- `src/index.ts` — HTTP-сервер (Express + MCP Streamable HTTP transport)
